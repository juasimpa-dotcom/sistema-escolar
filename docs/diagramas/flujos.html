Flujos de proceso

Recorrido de las operaciones con más reglas de negocio: inscripción, notas, asistencia y licencias. Los rombos son decisiones; las elipses punteadas, salidas con error.

ProcesoInicio / finDecisión con salida alternativa

1. Inscripción de estudiante

La gestión se deriva del aula. El sistema rechaza estudiantes de otra unidad y evita una segunda inscripción activa en la misma gestión.

flow-inscripcion · servicio AcademicoService::inscribir

2. Registro y corrección de notas

La nota debe estar entre 0 y el puntaje máximo. La corrección exige observación, queda en historial y solo se permite una vez.

flow-notas · NotaService::registrar / modificar

3. Toma de asistencia

El servidor consulta las licencias aprobadas y fuerza el estado licencia. El profesor no puede revertir ese estado.

flow-asistencia · AsistenciaService::registrarToma

4. Solicitud y resolución de licencia

Solo el padre solicita para sus hijos. Solo dirección resuelve, y siempre desde el estado pendiente. En ambos resultados se notifica al padre.

flow-licencia · LicenciaService::solicitar / aprobar / rechazar
